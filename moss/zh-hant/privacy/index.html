Moss’s Club house 隱私權政策

生效日期：2026年11月4日

Moss’s Club house（以下簡稱「App」）由獨立開發者 Jongmin Lee 在 JML.Studio（以下簡稱「我們」）製作。本政策說明 App 使用哪些資訊、為什麼使用、誰協助我們處理這些資訊，以及我們保留多久。

摘要

  • 其他使用者永遠看不到你的姓名或電子郵件，只能看到你的信和一個大概的城市。
  • 信件和回信會傳送給 OpenAI 進行安全審核和翻譯。信不是由 OpenAI 寫的。
  • 你的大概城市來自你的網路連線。App 不使用 GPS。
  • 沒有第三方廣告，也不追蹤個人行為。我們按天統計自家 App 連結的開啟次數，不使用分析或廣告 SDK。
  • 你可以隨時在 App 中刪除你的帳戶和信件。

1. 我們蒐集的資訊

帳戶。當你用 Apple 或 Google 登入時，我們會收到一個帳戶識別碼和你的電子郵件地址（Apple 可能會提供一個私密轉傳地址）。我們不會儲存這些服務提供的你的姓名或大頭貼。如果你使用「使用 Apple 登入」，我們還會儲存一個加密的 Apple 權杖，以便在你刪除帳戶時撤銷你的 Apple 登入。

個人檔案。你的 App 語言、時區、大概的城市、你接受的條款版本，以及你上次活躍的時間。

信件和回信。你寫下的信件和回信的文字、它們的譯文、審核結果、感謝留言，以及遞送詳情，例如日期，以及你被提供或選擇了哪些信件。

安全紀錄。你送出的檢舉、針對你內容的檢舉、檢舉人所看到的被檢舉內容的副本、你封鎖的人，以及帳戶限制。

通知。如果你允許通知，則包括你裝置的推播權杖和平台。

推廣連結。開啟我們其他 App 的連結時，App 會傳送應用程式、連結顯示位置、平台和目的頁面。該請求使用你的登入工作階段。每日彙總表依這些欄位記錄次數，不儲存帳戶 ID 或 IP 位址。

給我們的訊息。如果你寄電子郵件給我們，則包括你的電子郵件地址和你寫的內容。

意見回饋。 App 內的意見回饋包括類型與內容、語言、平台、App 版本、接收時間及關聯帳戶。

本機草稿。未傳送的草稿儲存在裝置上，傳送前不會提交至伺服器。Android 備份規則將 App 資料排除在自動雲端備份和裝置間移轉之外。iOS 會將儲存草稿的資料夾標記為不參與備份。該設定是給作業系統的指示，不保證完全阻止備份或還原。燒掉草稿不會清除以前備份中的副本。

2. 大概位置

Moss 需要大致知道信件從哪裡來、到哪裡去。代管服務商根據你的 IP 位址估算城市。我們把座標取整到大約 10 公里，將大概城市與安全紀錄分開儲存。讀信的人只能看到這個城市。App 不會要求或使用裝置的定位服務。

為保障登入安全，暫時的請求限流紀錄中包含依 IP 建立的索引鍵。排程作業會刪除距離最後一次請求超過兩天的紀錄；作業延遲可能使刪除延後。工作階段紀錄不儲存 IP 位址或 User-Agent 值。這不表示代管服務商不保留網路或安全日誌。

3. 我們如何使用資訊

我們使用這些資訊來營運 App：讓你登入、在不同城市和時區之間遞送信件、翻譯信件、審核內容的安全性、在信件顯示有人可能需要協助時提供求助資源、發送通知、處理檢舉和封鎖、防止濫用並限制請求頻率、修正問題，以及回覆你的訊息。 我們也使用連結開啟次數的彙總資料來衡量自家 App 的推廣成效。我們不出售你的資訊、不建立個人廣告輪廓，也不向你投放定向廣告。

4. AI 審核與翻譯

在信件或回信送達之前，我們會把它的文字、語言，以及（對回信而言）作為上下文的原信，傳送給 OpenAI。OpenAI 會依照我們的寫信規則進行檢查，並加以翻譯。AI 從不撰寫或編輯你的信。 每次傳送信件、回信或修改內容前，App 都會單獨徵求你對上述 OpenAI 處理的同意，與接受使用條款分開。只有你同意後，內容才會傳送。

我們傳送請求時關閉了 OpenAI 的儲存選項。根據 OpenAI 的 API 政策，API 資料預設不會用於訓練其模型，但 OpenAI 可能會為了監測濫用而在有限期間內保留這些資料。請參閱 OpenAI 的隱私權政策。

5. 服務提供者

我們使用少數幾家服務提供者來營運 App：

  • Cloudflare 代管我們的伺服器和資料庫，並根據你的 IP 位址估算你的城市。
  • OpenAI 審核並翻譯信件和回信。
  • Apple 和 Google 提供登入服務，並透過它們的推播服務送達通知。通知中不包含信件文字。
  • GitHub 在私人儲存庫中以議題形式處理 App 內意見回饋和信件或回信檢舉。檢舉包括原因、檢舉人看到的內容、內容類型、語言、日期和檢舉編號。我們不會額外加入帳戶 ID 或電子郵件地址，但文字仍可能識別個人。

這些服務提供者可能會在美國和其他國家或地區處理資訊，並依照它們各自的條款和隱私權政策處理。

6. 我們保留資訊多久

只要你的帳戶存在，我們就會保留你的帳戶和信件。一封信最多遞送 14 天。如果無人回信，它會回到你手中。你可以燒掉一封退回的信和它的回信，這會刪除它們的文字、譯文和審核資料，只留下一筆表示這封信曾經存在的最少紀錄。

刪除帳戶時，我們會刪除帳戶、工作階段、你的信件和你寫的回覆。我們會撤銷持有的 Apple 登入權杖；如需你手動移除 Apple 存取權限，我們會提供操作指引。關聯的 GitHub 私人意見回饋會在7天內非同步刪除，清理完成後才算刪除完成。為查核安全問題，我們將你提交的檢舉和針對你內容的檢舉的原因、當時內容及處理狀態保留最多90天，不含使用者 ID，之後刪除。文字中仍可能含有可識別個人的資訊。Cloudflare D1 復原歷程可能依方案保留已刪除資料最多30天。其他服務商的紀錄遵循各自的保留規則。

意見回饋送達後，我們會從 Cloudflare D1 資料庫清除回饋內容。原始回饋議題及相關副本會在議題關閉後90天或收到後180天內刪除，以較早期限為準。未解決的回饋也會在收到後180天內刪除。

GitHub 中的檢舉議題及相關副本會在以下最早期限前刪除：收到後180天、議題關閉或管理員處理完檢舉後90天、帳戶刪除後90天。此期限適用於 GitHub 副本；上述安全紀錄遵循各自的保留期限。

刪除申請完成後，我們會保留驗證證明和申請中繼資料，直到完成後90天或收到後180天中的較早期限。對於未完成的申請，我們只保留完成工作所需的最少資訊。

7. 你的選擇與權利

你可以在「設定」>「刪除帳戶」中刪除你的帳戶。你可以在裝置設定中關閉通知。你可以封鎖任何寫信給你的人。

依據你所在的地區，你可能有權存取、更正、刪除或匯出你的資訊，或反對或限制我們對其的使用。如需提出請求，請寄電子郵件至 jmjplearner@gmail.com。你也可以向當地的資料保護主管機關申訴。

8. 兒童

App 不是為 13 歲以下的兒童設計的。如果你認為有低於該年齡的兒童正在使用 App，請聯絡我們，我們會刪除該帳戶。

9. 安全

資料透過 HTTPS 傳輸，對我們系統的存取受到限制，我們的記錄檔只記錄錯誤代碼，不記錄信件文字或帳戶 ID。沒有任何服務能做到絕對安全，所以請不要在信裡寫下可識別身分的資訊。

10. 本網站

本網站（包括發布本政策的頁面）使用 Google Analytics 4 來瞭解造訪情況。Google 可能會依據 Google 的隱私權政策，收到瀏覽器和裝置資訊、根據你的 IP 位址得出的大概位置、你瀏覽的頁面，以及 Cookie 或類似識別碼。App 本身不使用 Google Analytics。

11. 變更

如果我們更改本政策，會更新上方的生效日期。如果變更重要，我們會在其生效之前在 App 中告知你。
