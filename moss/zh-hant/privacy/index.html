Moss’s Club house 隱私權政策

生效日期：2026年11月16日

Moss’s Club house（以下簡稱「App」）由獨立開發者 Jongmin Lee 在 JML.Studio（以下簡稱「我們」）製作。本政策說明 App 使用哪些資訊、為什麼使用、誰協助我們處理這些資訊，以及我們保留多久。

摘要

  • 其他使用者永遠看不到你的姓名或電子郵件，只能看到你的信和一個大概的地區。
  • 信件和回信會傳送給 OpenAI 進行安全審核和翻譯。信不是由 OpenAI 寫的。寫給未來自己的信不會交給其他人。寫信畫面的提問開關預設是開啟的，開關開啟期間，當你在句子或段落結尾停下來時，到那時為止寫的內容會傳送給外部 AI 服務以取得一個問題，不需要你點選；關閉開關後這類傳送即停止。總結卡片和回顧只有在你要求時，信的內容才會傳送。
  • 你的大概城市來自你的網路連線。App 不使用 GPS。
  • 如果你填寫的年齡為 19 歲及以上，獎勵廣告可能是個人化或一般廣告。18 歲及以下的使用者每天簽到可領取 1 個火花。
  • 付費會員的付款由 Apple 或 Google 處理。我們不會收到信用卡號等付款資訊。
  • 你可以隨時在 App 中刪除你的帳戶和信件。

1. 我們蒐集的資訊

帳戶。當你用 Apple 或 Google 登入時，我們會收到一個帳戶識別碼和你的電子郵件地址（Apple 可能會提供一個私密轉傳地址）。我們不會儲存這些服務提供的你的姓名或大頭貼。如果你使用「使用 Apple 登入」，我們還會儲存一個加密的 Apple 權杖，以便在你刪除帳戶時撤銷你的 Apple 登入。

個人檔案。你的 App 語言、時區、大概的城市、你接受的條款版本、你上次活躍的時間，以及你選擇的年齡區間（18 歲及以下，或年滿 19 歲）。App 只會詢問一次年齡區間：在你第一次將新的煩惱信或鼓勵信裝進信封時、在沒有信件送達的書桌上，或在商店的每日獎勵中。我們不詢問出生日期。

信件和回信。你寫下的信件和回信的文字、它們的譯文、審核結果、感謝留言，以及遞送詳情，例如日期，以及你被提供或選擇了哪些信件。

寫給未來自己的信。你寫的信的內文、寄出時印在信紙上的問題、寄出的時間和日期、你選擇的回來的日期、抵達通知和提前通知的傳送時間、你閱讀的時間、為總結卡片和回顧挑選的段落、你產生的每個回顧的種類和期間，以及你要求問題、總結卡片和回顧的次數。

安全紀錄。你送出的檢舉、針對你內容的檢舉、檢舉人所看到的被檢舉內容的副本、你封鎖的人，以及帳戶限制。

通知。如果你允許通知，則包括你裝置的推播權杖和平台。

推廣連結。開啟我們其他 App 的連結時，App 會傳送應用程式、連結顯示位置、平台和目的頁面。該請求使用你的登入工作階段。每日彙總表依這些欄位記錄次數，不儲存帳戶 ID 或 IP 位址。

給我們的訊息。如果你寄電子郵件給我們，則包括你的電子郵件地址和你寫的內容。

意見回饋。 App 內的意見回饋包括類型與內容、語言、平台、App 版本、接收時間及關聯帳戶。

會員。你購買或恢復會員時，我們會接收並驗證 App 商店的購買憑證：在 App Store 上是 Apple 簽署的交易，在 Google Play 上是購買權杖。我們會將其中的交易識別碼或購買權杖、商品和方案、到期時間以及我們上次驗證的時間與你的帳戶一起保存；對於 App Store 購買，也會保存購買時間。Google Play 購買的權杖和商品會另外保存，直到向 Google 完成購買確認為止。訂閱續訂、到期或退款時，Apple 會通知我們的伺服器。對於已退款或被撤銷的 App Store 購買，我們會記錄交易識別碼、購買時間，以及退款和其通知送達的時間。在你的帳戶存在期間，這筆紀錄會與帳戶連結，以便在退款被撤銷時恢復會員；刪除帳戶會解除這項連結。購買時，App 會向 App 商店傳遞一個由你的帳戶 ID 產生的識別碼。它看起來是隨機的，你帳戶的每次購買都使用同一個值；它不是你的帳戶 ID 或電子郵件本身。信用卡號等付款資訊由 Apple 或 Google 處理，我們不會收到。對於已取消的 Google Play 終身會員購買，我們只記錄購買權杖的雜湊值和確認取消的時間，不與你的帳戶連結。

專注收集品。你用專注計時完成專注時段後收集到的物品。我們會把你收集了哪些物品、每件物品首次收集的時間，以及每個專注地點的資料一併保存在帳戶中：在該地點完成的專注總時間、最近一次在該地點完成專注的當地日期、當天完成的專注時間，以及連續天數。為合併不同裝置上的連續紀錄，必要時也會保存截至該日期的七天內，你在哪幾天於該地點完成過專注。為合併不同裝置的紀錄來確認是否達成每日或連續天數目標，我們也會儲存各地點最近一次計入統計的專注結束時間，以及你開始該時段時是否具備會員資格。為避免多部裝置的儲存互相衝突，我們也會儲存 App 在每部裝置上產生的隨機安裝識別碼，以及最近一次儲存的檢查值。這樣你重新安裝 App 後可以找回收集品，也能在其他裝置上看到。

商店獎勵。我們保留你選擇的年齡區間（18 歲及以下，或年滿 19 歲）以及選擇或上次變更的時間。我們不詢問出生日期。我們記錄每日獎勵的日期和數量。廣告嘗試記錄包括帳號、工作階段、廣告單元、時間，以及發放獎勵時的 Google 交易參考資料雜湊值。

你裝置上的資料。未傳送的草稿儲存在裝置上，傳送前不會提交至伺服器。專注計時的紀錄（每天的專注時間）和設定同樣只保存在你的裝置上，不會傳送到伺服器。Android 備份規則將 App 資料排除在自動雲端備份和裝置間移轉之外。iOS 會將儲存草稿的資料夾標記為不參與備份。該設定是給作業系統的指示，不保證完全阻止備份或還原。燒掉草稿不會清除以前備份中的副本。你的打字機的顏色和型號、貼紙和特效、打字聲、提問開關以及寫信畫面的檢視方式，也只保存在你的裝置上，不會傳送到伺服器。為貼紙記住的城市名稱（你的信往來過的城市）也是如此；刪除信件後仍會保留，在 App 中刪除帳戶時會從該裝置上刪除。小工具只會在裝置上收到下列資料：主畫面小工具會收到已送達信件的數量，iOS 的鎖定畫面小工具會收到已送達信件的數量、你是否具備會員資格、你寄出的信正前往的城市名稱和預計抵達時間，以及正在進行的專注計時。信件內文和信件識別碼絕不會傳給小工具。

2. 大概位置

Moss 需要大致知道信件從哪裡來、到哪裡去。代管服務商根據你的 IP 位址估算城市。我們把座標取整到大約 10 公里，將大概城市與安全紀錄分開儲存。其他使用者只能看到範圍更大的地區名稱，或同一個國家中最近的大城市名稱。App 不會要求或使用裝置的定位服務。

為保障登入安全，暫時的請求限流紀錄中包含依 IP 建立的索引鍵。排程作業會刪除距離最後一次請求超過兩天的紀錄；作業延遲可能使刪除延後。工作階段紀錄不儲存 IP 位址或 User-Agent 值。這不表示代管服務商不保留網路或安全日誌。

3. 我們如何使用資訊

我們使用這些資訊來營運 App：讓你登入、在不同城市和時區之間遞送信件、在我們開啟依年齡區間遞送期間只在同一年齡區間的使用者之間傳遞信件、翻譯信件、審核內容的安全性、為寫給未來自己的信在寫信時產生提問，並在你提出要求時產生總結卡片或回顧、在信件顯示有人可能需要協助時提供求助資源、發送通知、處理檢舉和封鎖、防止濫用並限制請求頻率、修正問題，以及回覆你的訊息。 我們也使用連結開啟次數的彙總資料來衡量自家 App 的推廣成效。

商店資料用於套用年齡和每日獎勵上限、確認廣告觀看完成、發放火花，以及防止濫用和重複發放。會員資料用於確認會員購買並提供會員權益，以及防止已退款的購買被再次使用。專注收集品用於在你重新安裝後找回收集品，並在其他裝置上顯示。

4. AI 審核與翻譯

在信件或回信送達之前，我們會把它的文字、語言，以及（對回信而言）作為上下文的原信，傳送給 OpenAI。OpenAI 會依照我們的寫信規則進行檢查，並加以翻譯。AI 從不撰寫或編輯你的信。 新版 App 會在初次設定或查看更新後的協議時，在使用條款頁面徵求你對上述處理的同意。該同意也適用於之後傳送的信件、回信和修改內容。舊版 App 會在每次傳送時徵求同意。

寫給未來自己的信。這類信不會交給其他人，因此不經過審核和翻譯。我們透過兩種方式將信傳送給外部 AI 服務。第一，提問會自動出現。寫信畫面的提問開關預設是開啟的，開關開啟期間，當你在句子或段落結尾停下來時，我們會將你到那時為止寫的內容、這封信已經出現過的問題和 App 語言傳送給外部 AI 服務，不需要你點選，並收到一個問題。已經出現過的問題包括印在信紙上的問題，以及收到後已不在信紙上的問題（例如你移除的問題），最多五個；傳送這些問題是為了避免同一個問題再次出現。這類傳送在每封信和每天都有次數上限（使用條款第 7 節）。如果你關閉開關，這封信和之後的信都不會再為提問傳送任何內容，直到你再次開啟。這項選擇儲存在該裝置上，因此在其他裝置上或重新安裝 App 後，開關會重新以開啟狀態開始。在我們關閉自動出現的提問期間，開關會改為按鈕，只有在你按下時才會傳送相同的項目。第二，總結卡片和回顧只有在你提出要求時才會傳送。如果你為已回來的信要求產生總結卡片，我們會傳送這封信的內文，並收到從信中挑選的最多三段文字。如果你要求回顧（我的一週、我的一個月或我的一年），我們會傳送該期間內已回來的信的內文和寫信日期，並收到從這些信中挑選的段落。尚未回來的信不會傳送。新信的信紙上會印有一個通用問題。它來自 App 內建的清單，依你裝置的日期挑選，不使用 AI。挑選和印上這個問題時不會傳送到任何地方。這個問題也算在這封信已經出現過的問題中，因此會如上所述隨之後的每次提問一起傳送。所有問題都會顯示得像是 Moss 在用他的口吻發問。最開頭的那個問題來自 App 內建的清單，不會為它傳送任何內容。之後你寫信時出現的問題，是外部 AI 服務根據你到那時為止寫的內容產生的，不是由人撰寫的。在你寄出這封信之前，我們不會保存或記錄寫信時與 AI 服務交換的內容和問題。寄出信件後，印在信紙上的問題會與信一起保存，信回來時會再次顯示在信上，並隨信一起刪除。總結卡片和回顧會與你的信一起保存，同時保存提出要求的次數。總結卡片和回顧只傳送信本身的內容，不會傳送這些問題。如果你關閉開關，也從不要求產生總結卡片或回顧，你的信就不會傳送給 AI 服務。你對這項處理的同意，會在你首次啟動或查看更新後的條款並點選「我同意」時，與你接受條款一併記錄。

如需撤回同意，請在「設定」>「刪除帳戶」中刪除帳戶，或寄電子郵件至 jmjplearner@gmail.com。撤回後，你將無法再寄出信件、回信或鼓勵信，因為它們需要經過 AI 服務處理。

具有儲存回應選項的請求，傳送時會關閉該選項。根據 OpenAI 的 API 政策，API 資料預設不會用於訓練其模型，但 OpenAI 可能會為了監測濫用而在有限期間內保留這些資料。請參閱 OpenAI 的隱私權政策。

5. 服務提供者

我們使用少數幾家服務提供者來營運 App：

  • Cloudflare 代管我們的伺服器和資料庫，並根據你的 IP 位址估算你的城市。
  • OpenAI 審核並翻譯信件和回信。對於寫給未來自己的信，開關開啟期間它會根據到那時為止寫的內容產生問題；總結卡片和回顧只在你提出要求時才會收到信的內容。
  • Apple 和 Google 提供登入服務。通知透過 Apple Push Notification service（APNs）和 Firebase Cloud Messaging（FCM）傳送，不含信件正文。
  • Google AdMob 和同意管理工具（UMP）可能接收你的 IP 位址、根據 IP 位址推算的概略位置、App 和裝置資訊（包括可用的識別碼）、廣告曝光和互動紀錄，以及當機或效能資料。Google 使用這些資料管理同意、放送及評估廣告，並防止詐欺。我們停用發布商第一方識別碼。為核實獎勵，我們只在自訂資料中傳送不含身分資訊的嘗試權杖。我們不會向廣告供應商傳送你的 App 帳號 ID、電子郵件地址或信件正文。Google 依照其隱私權政策處理及保留 SDK 資料。
  • GitHub 在私人儲存庫中以議題形式處理 App 內意見回饋和信件或回信檢舉。檢舉包括原因、檢舉人看到的內容、內容類型、語言、日期和檢舉編號。我們不會額外加入帳戶 ID 或電子郵件地址，但文字仍可能識別個人。
  • Apple（App Store）和 Google（Google Play）在你購買或恢復會員時處理付款。它們會收到由你的帳戶 ID 產生的識別碼（不是帳戶 ID 或電子郵件本身），對於 Google Play，還會收到購買權杖和商品識別碼。對於 Google Play 的購買，我們的伺服器在確認購買、向 Google 完成購買確認或再次驗證訂閱時，也會與 Google 通訊。你的付款方式和付款資訊由你直接提供給 App 商店，不經過我們。不會傳送信件內容。除非你購買會員，否則不會傳送任何資料。

在 iOS 上，首次選擇觀看符合條件的廣告時，Apple 可能透過 App 追蹤透明度（ATT）請求許可。如果你允許追蹤且 Google 的地區性同意允許個人化，我們會要求個人化廣告。如果你拒絕追蹤，而 Google 允許要求廣告，我們會要求一般廣告。如果 ATT 授權和其他必要的同意均允許，Google 也可能在放送一般廣告時使用 iOS 廣告識別碼（IDFA）來評估廣告成效或限制顯示頻率。在 Android 上，設定中的個人化廣告開關預設關閉。在 Android 上，我們會封鎖廣告 ID 和 AdServices 廣告相關權限。選擇個人化廣告後，是否按個人化方式處理取決於 Google 的規則及可用資料。Google 仍可能放送一般廣告。個人化未獲允許時，如果 Google 的工具允許要求廣告，我們會要求一般廣告。如果該工具不允許要求廣告，我們不會要求廣告。

這些服務提供者可能會在美國和其他國家或地區處理資訊，並依照它們各自的條款和隱私權政策處理。

6. 我們保留資訊多久

只要你的帳戶存在，我們就會保留你的帳戶和信件。一封信最多遞送 14 天。如果無人回信，它會回到你手中。你可以燒掉一封退回的信和它的回信，這會刪除它們的文字、譯文和審核資料，只留下一筆表示這封信曾經存在的最少紀錄。寫給未來自己的信（內文、印在信紙上的問題、寄出時間、回來的日期、閱讀時間、總結卡片、為回顧挑選的段落）會保留到你刪除該信或刪除帳戶。刪除信件時，內文、印在信紙上的問題、總結卡片以及從該信中為回顧挑選的段落會被刪除；一個隨機識別碼和寄出日期會保留到你刪除帳戶，以免同一封信被重複寄出。所產生回顧的類型和期間保留到你刪除帳戶，提問、總結卡片和回顧的要求次數由定期作業在 7 天後刪除。

刪除帳戶時，我們會刪除帳戶、工作階段、你的信件和你寫的回覆。我們會撤銷持有的 Apple 登入權杖；如需你手動移除 Apple 存取權限，我們會提供操作指引。關聯的 GitHub 私人意見回饋會在7天內非同步刪除，清理完成後才算刪除完成。為查核安全問題，我們將你提交的檢舉和針對你內容的檢舉的原因、當時內容及處理狀態保留最多90天，不含使用者 ID，之後刪除。文字中仍可能含有可識別個人的資訊。會員資料（商品、交易識別碼或購買權杖、到期時間）和專注收集品保留到你刪除帳戶，並隨帳戶一併刪除。已退款或被撤銷的 App Store 購買的交易識別碼和時間保存3年，用於防止已退款的購買被再次使用，並在退款被撤銷時恢復會員。帳戶存在期間與你的帳戶連結，你刪除帳戶後以不含帳戶資料的方式保存。已取消的 Google Play 終身會員購買的權杖雜湊值和取消確認時間自最後一次確認起保存3年，同樣不含帳戶資料，刪除帳戶後仍會保留，用於防止已取消的購買被再次使用。Cloudflare D1 復原歷程可能依方案保留已刪除資料最多30天。其他服務商的紀錄遵循各自的保留規則。

意見回饋送達後，我們會從 Cloudflare D1 資料庫清除回饋內容。原始回饋議題及相關副本會在議題關閉後90天或收到後180天內刪除，以較早期限為準。未解決的回饋也會在收到後180天內刪除。

GitHub 中的檢舉議題及相關副本會在以下最早期限前刪除：收到後180天、議題關閉或管理員處理完檢舉後90天、帳戶刪除後90天。此期限適用於 GitHub 副本；上述安全紀錄遵循各自的保留期限。

刪除申請完成後，我們會保留驗證證明和申請中繼資料，直到完成後90天或收到後180天中的較早期限。對於未完成的申請，我們只保留完成工作所需的最少資訊。

廣告選擇依帳號儲存在這部裝置上。目前的年齡區間、設定時間及已發放的獎勵紀錄保留至帳號刪除。相關每日獎勵時段結束滿一天後，定期作業會刪除廣告嘗試紀錄，刪除帳號時也會清除。Google 處理的資料適用其自身的保留規則。
