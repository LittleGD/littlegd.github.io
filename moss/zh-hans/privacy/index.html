Moss’s Club house 隐私政策

生效日期：2026年11月4日

Moss’s Club house（以下简称“App”）由独立开发者 Jongmin Lee 在 JML.Studio（以下简称“我们”）制作。本政策说明 App 使用哪些信息、为什么使用、谁协助我们处理这些信息，以及我们保留多久。

摘要

  • 其他用户永远看不到你的姓名或邮箱，只能看到你的信和一个大概的城市。
  • 信件和回信会发送给 OpenAI 进行安全审核和翻译。信不是由 OpenAI 写的。
  • 你的大概城市来自你的网络连接。App 不使用 GPS。
  • 没有第三方广告，也不追踪个人行为。我们按天统计自家 App 链接的打开次数，不使用分析或广告 SDK。
  • 你可以随时在 App 中删除你的账户和信件。

1. 我们收集的信息

账户。当你用 Apple 或 Google 登录时，我们会收到一个账户标识符和你的邮箱地址（Apple 可能会提供一个私密中继地址）。我们不会保存这些服务提供的你的姓名或头像。如果你使用“通过 Apple 登录”，我们还会保存一个加密的 Apple 令牌，以便在你删除账户时撤销你的 Apple 登录。

个人资料。你的 App 语言、时区、大概的城市、你接受的条款版本，以及你上次活跃的时间。

信件和回信。你写下的信件和回信的文本、它们的译文、审核结果、感谢留言，以及递送详情，例如日期，以及你被提供或选择了哪些信件。

安全记录。你发出的举报、针对你内容的举报、举报人所看到的被举报内容的副本、你屏蔽的人，以及账户限制。

通知。如果你允许通知，则包括你设备的推送令牌和平台。

推广链接。打开我们其他 App 的链接时，App 会发送应用、链接展示位置、平台和目标页面。该请求使用你的登录会话。每日汇总表按这些字段记录次数，不保存账户 ID 或 IP 地址。

给我们的消息。如果你给我们发邮件，则包括你的邮箱地址和你写的内容。

反馈。 应用内反馈包括类型和内容、语言、平台、应用版本、接收时间及关联账户。

本地草稿。未发送的草稿保存在设备上，发送前不会提交到服务器。Android 备份规则将 App 数据排除在自动云备份和设备间迁移之外。iOS 会将保存草稿的文件夹标记为不参与备份。该设置是给操作系统的指示，不保证完全阻止备份或恢复。烧掉草稿不会清除以前备份中的副本。

2. 大概位置

Moss 需要大致知道信件从哪里来、到哪里去。托管服务商根据你的 IP 地址估算城市。我们把坐标取整到大约 10 公里，将大概城市与安全记录分开保存。读信的人只能看到这个城市。App 不会请求或使用设备的定位服务。

为保障登录安全，临时请求限流记录中包含基于 IP 的键。定时任务会删除距离最后一次请求超过两天的记录；任务延迟可能使删除延后。会话记录不保存 IP 地址或 User-Agent 值。这不表示托管服务商不保留网络或安全日志。

3. 我们如何使用信息

我们使用这些信息来运行 App：让你登录、在不同城市和时区之间递送信件、翻译信件、审核内容的安全性、在信件显示有人可能需要帮助时展示求助资源、发送通知、处理举报和屏蔽、防止滥用并限制请求频率、修复问题，以及回复你的消息。 我们也使用链接打开次数的汇总数据来衡量自家 App 的推广效果。我们不出售你的信息，不建立个人广告画像，也不向你投放定向广告。

4. AI 审核与翻译

在信件或回信送达之前，我们会把它的文本、语言，以及（对回信而言）作为上下文的原信，发送给 OpenAI。OpenAI 会依照我们的写信规则进行检查，并加以翻译。AI 从不撰写或编辑你的信。 每次发送信件、回信或修改内容前，App 都会单独征求你对上述 OpenAI 处理的同意，与接受使用条款分开。只有你同意后，内容才会发送。

我们发送请求时关闭了 OpenAI 的存储选项。根据 OpenAI 的 API 政策，API 数据默认不会用于训练其模型，但 OpenAI 可能会为监测滥用而在有限期间内保留这些数据。请参阅 OpenAI 的隐私政策。

5. 服务提供商

我们使用少数几家服务提供商来运行 App：

  • Cloudflare 托管我们的服务器和数据库，并根据你的 IP 地址估算你的城市。
  • OpenAI 审核并翻译信件和回信。
  • Apple 和 Google 提供登录服务，并通过它们的推送服务送达通知。
  • Expo 将通知转发给 Apple 和 Google。通知中不包含信件文本。
  • GitHub 在私有仓库中以议题形式处理应用内反馈和信件或回信举报。举报包括原因、举报人看到的内容、内容类型、语言、日期和举报编号。我们不会额外添加账户 ID 或电子邮箱地址，但文本仍可能识别个人。

这些服务提供商可能会在美国和其他国家或地区处理信息，并依照它们各自的条款和隐私政策处理。

6. 我们保留信息多久

只要你的账户存在，我们就会保留你的账户和信件。一封信最多递送 14 天。如果无人回信，它会回到你手中。你可以烧掉一封退回的信和它的回信，这会删除它们的文本、译文和审核数据，只留下一条表明这封信曾经存在的最少记录。

删除账户时，我们会删除账户、会话、你的信件和你写的回复。我们会撤销所持有的 Apple 登录令牌；如需你手动移除 Apple 访问权限，我们会提供操作指引。关联的 GitHub 私人反馈会在7天内异步删除，清理完成后才算删除完成。为核查安全问题，我们将你提交的举报和针对你内容的举报的原因、当时内容及处理状态保留最多90天，不含用户 ID，之后删除。文本中仍可能含有可识别个人的信息。Cloudflare D1 恢复历史可能根据套餐保留已删除数据最多30天。其他服务商的记录遵循各自的保留规则。

反馈送达后，我们会从 Cloudflare D1 数据库中清除反馈内容。原始反馈议题及相关副本将在议题关闭后90天或收到后180天内删除，以较早期限为准。未解决的反馈也会在收到后180天内删除。

GitHub 中的举报议题及相关副本会在以下最早期限前删除：收到后180天、议题关闭或管理员处理完举报后90天、账户删除后90天。此期限适用于 GitHub 副本；上述安全记录遵循各自的保留期限。

删除申请完成后，我们会保留验证证明和申请元数据，直至完成后90天或收到后180天中的较早期限。对于未完成的申请，我们只保留完成工作所需的最少信息。

7. 你的选择和权利

你可以在“设置”>“删除账户”中删除你的账户。你可以在设备设置中关闭通知。你可以屏蔽任何给你写信的人。

根据你所在的地区，你可能有权访问、更正、删除或导出你的信息，或反对或限制我们对其的使用。如需提出请求，请发邮件至 jmjplearner@gmail.com。你也可以向当地的数据保护机构投诉。

8. 儿童

App 不面向 13 岁以下的儿童。如果你认为有低于该年龄的儿童正在使用 App，请联系我们，我们会删除该账户。

9. 安全

数据通过 HTTPS 传输，对我们系统的访问受到限制，我们的日志只记录错误代码，不记录信件文本或账户 ID。没有任何服务能做到绝对安全，所以请不要在信里写下可识别身份的信息。

10. 本网站

本网站（包括发布本政策的页面）使用 Google Analytics 4 来了解访问情况。Google 可能会依据 Google 的隐私政策，收到浏览器和设备信息、根据你的 IP 地址得出的大概位置、你浏览的页面，以及 Cookie 或类似标识符。App 本身不使用 Google Analytics。

11. 变更

如果我们更改本政策，会更新上方的生效日期。如果变更重要，我们会在其生效之前在 App 中告知你。
